## 5. 复查步骤与测试限制

1. 打开[清洗报告](../../../reports/w3_cleaning_report.md)核对人数、缺失和拆分；打开[Notebook 浏览器版](../../../notebooks/03_cleaning.html)查看实际执行结果。
2. 查看三份机器证据：`w3_verification.json`、`w3_test_results.json`、`w3_clean_environment_verification.json`。通过、失败、未请求和跳过是不同状态，不能只看文件是否存在。
3. 需要重跑时，按[操作说明](../../operations/W3_run_and_delivery.md)执行 `run_week3.py --verify-reproducibility` 和 `test_week3.py`。变更数据/代码后应重新验收，旧 JSON 不代表新版本自动通过。
4. 文件总清单的 SHA 对应本次最终交付快照。后续修改 README、重跑 Notebook 或重新拟合二进制会改变相应文件指纹；不要据此倒推本次业务数据复现失败。

主环境与隔离环境各执行 52 项测试：51 项通过、0 失败、0 错误、1 跳过。唯一跳过项是当前 Windows 权限无法创建单文件符号链接（WinError 1314），机器证据和日志已明确列出。目录重定向使用 junction 实际测试，硬链接保护也实际通过；这些场景使用安全临时文件，不对真实原始数据试写。
