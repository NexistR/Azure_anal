## 主要结论

| 主题 | 本次结果 | 解释边界 |
|---|---|---|
| H1 合同 | 月付、一年期、两年期的观察流失率分别为 42.71%、11.27%、2.83%；合同总体关联 V=0.4101 | 通过静态关联比较，不证明改变合同能挽留客户 |
| H2 年限 | `[0,6)` 月组 54.27%，`[48,73)` 月组 9.64%；ρ=−0.3671 | 通过横截面关联比较，不是前六个月的未来流失概率 |
| H4 服务 | 互联网客户内 0 项与 6 项增值服务组分别为 52.24%、5.28%；全体 0 项组因混入无互联网客户降为 21.41% | 部分通过；必须写清人群与六服务定义 |
| H5 费用×服务 | 高月费互联网客户中，0–2 项服务组 53.30%，3–6 项组 23.47% | 部分通过；DSL 对应小组只有 3 人，不能泛化到所有网络，也未测量价格感知 |
| H6 支付 | 手动/自动组分别为 34.67%/15.98%；手动组内电子与邮寄支票差异明显 | 部分通过；无支付失败事件或续约证据 |
| H9 细分 | 部分人口细分基线有差异，性别校正后不显著 | 部分通过；未验证各细分驱动权重，也无 Azure 地区/行业维度 |
| H10 风险×价值 | 规则“月付且 tenure<6”与月费≥70.35 命中 485 人，占 6.89%，观察流失率 74.23% | 部分通过；规则矩阵为描述雏形，不是模型概率、正式 CLV 或资源分配效果 |

因此结果为 **2 项通过、5 项部分通过、3 项不可验证**。不可验证项分别是 H3（缺真实使用时间序列）、H7（工单无可靠共同客户键及时间口径）、H8（缺自动续费/历史续约）。没有把不可验证项或探索性统计显著性当作完整业务机制的验证。

全部发现仅适用于当前 Telco 公开代理样本。MonthlyCharges 只作当前月费价值代理，币种没有额外推断；任何率值或费用合计均不直接表述为 Azure 实测、未来流失、真实利润或可挽回收入。
