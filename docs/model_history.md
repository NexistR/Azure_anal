# 历史模型性能对照报告

历史记录形成于2026-10-14，覆盖 W5 基线、W6v1–v8 研究及续作 W6v9、W6v10。精度调优已于2026-10-16终止，后续仅完成解释、风险、运行效率和分群分析。本公开副本保留当时的模型指标与评价边界；文中的轮次、候选和未执行提议均为历史记录，不构成待办计划。

**目前仍未达到 AUC > 0.88、流失正类 F1 > 0.80、至少三个稳定细分的目标。** 保留模型为 W6v1 XGBoost，历史复用 validation 上 AUC=0.852193、正类 F1=0.656160、稳定细分=2/10。本次两轮增加了训练路线并得到小幅 OOF 改善，但两次锁定后的新融合验证均未超过该模型。

报告形成时，续作计划记录为2/5轮，此后调优已终止，未继续完成其余轮次，也未进入新增真实客户数据阶段。旧文档中的“五轮最终版”指已完成的v4–v8；从v9重新计数的续作仅完成v9、v10两轮。

## 数据与比较口径

任务书的三个数据源分别为 Telco Customer Churn、Customer Support Tickets、SaaS Churn Rate Statistics。Telco 共 7,043 个客户、21 个原始字段，实际可用预测信息为19个原始业务字段及3个确定性清洗标记；W4派生为64个逻辑字段，独热编码后111列。它们不是新增真实业务观测。

Tickets 为8,469条工单，SaaS为10个工作表共50条汇总记录。两者没有经过验证的同客户映射和预测前时间信息，所以没有伪拼接进 Telco 监督模型。该项目目前是客户流失方法的公开数据代理分析，不能把现有字段描述为真实 Azure 的 VM、存储或 API 行为数据。

| 数据部分 | 客户数 | 正类数 | 使用方式 |
|---|---:|---:|---|
| train | 4,930 | 1,308 | 原seed=42五折；预处理及模型在折内拟合 |
| validation | 1,056 | 280 | 已多次复用的开发验证集；不是新盲测 |
| historical test | 1,057 | 281 | 仅引述既有W5 Logistic成绩；本次未新增预测或评分 |

F1 始终指 `label=1` 流失客户的 binary F1，不使用 macro、weighted 或负类 F1 替代。OOF 是每个训练客户由未见过它的外折模型给出的预测；同一 OOF 上选模型和阈值仍有选择偏差。历史 mean-fold CV 指标、pooled OOF、validation、historical test 分列，未互相填补缺失值。

早期模型阈值选自 validation；后续受控路线在训练 OOF 上选择并冻结阈值。比较保留各自原阈值及来源。后续主筛选指标为 min(F1/0.80, AUC/0.88)，再按预登记规则打破并列，不以训练拟合分数验收。

原数据与可行性审查（原归档：`reports/w6v2/feasibility_review.md`；未随公开副本提供） · 本次三源与轮次协议（原归档：`configs/w6_continuation_protocol.json`；未随公开副本提供）

## 历史test与细分稳定性

历史test只实际评价过同一个W5冻结Logistic，W5与v1的记录是重复阶段引用：阈值0.35，AUC=0.847429、正类F1=0.622735、AP=0.676500。**该成绩不属于当前XGBoost，也不属于v9/v10融合。** 原test已暴露，不能重新命名为新盲测。原成绩来源（原归档：`reports/w5/tables/test_metrics.csv`；未随公开副本提供）

稳定性继续覆盖Contract、InternetService、tenure_band三个维度共十层，原门槛为n≥100、正类≥20、负类≥20。样本量合格的8层各与同一评价集整体进行500次配对bootstrap，共4,000次；另外2层标记insufficient_data，不进行bootstrap。AUC和F1差值的95%配对区间下限分别严格高于−0.10和−0.15，才记stable。

| validation模型 | 稳定细分 | 其余说明 |
|---|---|---|
| 保留的XGBoost | Fiber optic；tenure 13–24，共2/10 | 未达到至少3层 |
| v9融合 | 同上，共2/10 | 未提高稳定层数量 |
| v10融合 | 同上，共2/10 | 10层独立复核结论一致 |

Two year仅7个正类，InternetService=No仅15个正类，低于原样本量要求。没有通过降低门槛、重划分段或舍弃不利客户制造稳定结论。两层可重叠，计数不能理解为三个维度均稳定，也不代表时间外鲁棒性。

## 失败结论与已封存的研究范围

目前没有发现标签方向、概率方向、OOF回填或大规模重复串分区错误，能够通过简单修复填补目标差距。已执行的方法仍只利用现有19类原始业务信息；学习曲线、同画像冲突和固定分数的阈值极值都不足以证明所有可能模型的理论上限。

本轮已修复排序损失归一化导致的训练退化、TabICL的序列化QA误报，并保留失败与恢复记录。工程问题修复后，实际外折性能仍未超过准入参考；不能把“代码运行成功”当作“性能达标”。失败尝试与评价边界（原归档：`week6_sub/整理报告_2026-10-14/05_失败尝试与评价边界.md`；未随公开副本提供）

历史续作停在2/5轮。曾提议在第3轮比较固定TabM架构上的CE与soft-F1混合目标，但该方案未执行，现已封存。原定“前五轮仅用原三源、第五轮后再评估新增真实数据”的后续安排也随2026-10-16停止调优而终止；本项目未据此新增真实客户数据，更未用另一数据集替换原任务来宣称达标。
