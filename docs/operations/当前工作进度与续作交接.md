- 公开 Telco 数据只能称为代理数据或教学数据，不能称为微软 Azure 真实客户数据。
- brief 中的流失率、AUC、F1、ROI 等是背景或验收目标，不是当前实测结果。
- 没有共同客户 ID 和一致时间口径时，不强行拼接 Telco、工单和 SaaS 数据。
- 原始数据保持只读；清洗结果写入 `data/processed`。
- 不把账号、密钥、连接字符串、个人信息或原始客户数据提交到 Git。
- 建模前先固定标签、预测窗口和时间边界，防止数据泄漏。
