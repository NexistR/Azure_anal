## 2. 第一次打开项目

打开一个新的 PowerShell 窗口。新窗口可以读取 Git 和 Azure CLI 安装后更新的 `PATH`。

```powershell
cd "G:\VScode\pj_mic\azure-churn-clv"
code .
```

VS Code 已将默认解释器配置为：

```text
G:\VScode\pj_mic\azure-churn-clv\.venv\Scripts\python.exe
```

打开 Notebook 时，在右上角内核选择器中选择 `Python (.venv) - pj_mic`。如果状态栏显示的是其他 Python，按 `Ctrl+Shift+P`，运行 `Python: Select Interpreter`，再选择项目 `.venv`。

## 3. 在终端中使用 Python 和 Jupyter

每次新开普通 PowerShell 后，先进入项目并激活虚拟环境：

```powershell
cd "G:\VScode\pj_mic\azure-churn-clv"
.\.venv\Scripts\Activate.ps1
python --version
```

如果 PowerShell 阻止脚本执行，只对当前窗口临时放行：

```powershell
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
.\.venv\Scripts\Activate.ps1
```

启动 JupyterLab：

```powershell
python -m jupyter lab
```

浏览器会打开本地页面。工作结束后回到终端按 `Ctrl+C` 停止服务。

## 4. 验证整个分析环境

在项目根目录运行：

```powershell
.\.venv\Scripts\python.exe -m pip check
.\.venv\Scripts\python.exe tools\check_environment.py --advanced --optional
.\.venv\Scripts\python.exe tools\smoke_test_stack.py --advanced --spark
```

最后一条命令会实际训练小模型并启动一个本地 Spark 会话，而不只是检查能否导入包。成功时最后会看到：

```text
All requested smoke tests passed.
```

Spark 在 Windows 上可能提示找不到 `winutils.exe` 或原生 Hadoop 库。本项目的小规模本地 DataFrame 运算会自动使用 Java 实现，这类警告不影响当前测试。若以后使用 HDFS、生产级 Spark 集群或大量数据，建议改用 Azure Databricks、Azure Synapse 或 Linux/WSL 环境。

## 5. 使用 PySpark

从 VS Code 内置终端启动时，`.vscode/settings.json` 会自动设置 Java 和 Python 路径。若从普通 PowerShell 直接运行 PySpark，先执行：

```powershell
cd "G:\VScode\pj_mic\azure-churn-clv"
$env:JAVA_HOME = (Resolve-Path ".\.tools\jdk-17").Path
$env:PYSPARK_PYTHON = (Resolve-Path ".\.venv\Scripts\python.exe").Path
$env:PYSPARK_DRIVER_PYTHON = $env:PYSPARK_PYTHON
.\.venv\Scripts\python.exe -c "from pyspark.sql import SparkSession; s=SparkSession.builder.master('local[1]').getOrCreate(); print(s.version); s.stop()"
```

JDK 放在项目内部，不会替换系统中已有的 Java，也不会永久修改整台电脑的 `JAVA_HOME`。

## 7. 使用 Azure CLI

Azure CLI 已安装，但尚未登录任何账号，也没有替你创建订阅或收费资源。请在新的 PowerShell 中手动完成：

```powershell
az version
az login
az account list --output table
az account set --subscription "你的订阅名称或订阅 ID"
az account show --output table
```

`az login` 会打开浏览器，账号登录、多重验证和订阅选择必须由你本人完成。若终端暂时提示找不到 `az`，关闭后重新打开 PowerShell；安装路径是：

```text
C:\Program Files\Microsoft SDKs\Azure\CLI2\wbin\az.cmd
```

开始创建 Azure 资源前，先在 Azure Portal 设置预算和费用告警。不要把账号密码、访问密钥、连接字符串或服务主体密钥写入 Notebook、`.env.example` 或 Git。

## 9. 在另一台电脑上重建环境

先安装 Python 3.12、VS Code 和 Git，然后在项目根目录运行：

```powershell
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
.\scripts\setup_environment.ps1 -IncludeAdvanced -IncludeSpark
```

该脚本会：

1. 创建或检查 Python 3.12 虚拟环境。
2. 安装锁定版本的核心、高级和 PySpark 依赖。
3. 下载、校验并配置项目本地 JDK 17。
4. 检查依赖冲突并注册 Jupyter 内核。
5. 运行导入检查和实际功能冒烟测试。

依赖文件的用途如下：

| 文件 | 用途 |
| --- | --- |
| `requirements.txt` | 默认核心环境 |
| `requirements-all.txt` | 核心环境加高级建模环境 |
| `requirements-optional.txt` | 可选 PySpark 环境，需要 JDK 17 |
| `requirements-core.txt` | 核心包的精确版本 |
| `requirements-advanced.txt` | 高级包的精确版本 |

安装脚本使用隔离的 pip 配置和单一 HTTPS 镜像，避免本机全局 pip 镜像设置干扰依赖解析。
