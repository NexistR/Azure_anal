# 文档目录

项目文档按用途分组，运行入口和依赖文件仍保留在仓库根目录。

- `project/`：项目背景、零基础实现指南和原始 brief。
- `planning/`：八周执行框架、周计划和路线图。
- `operations/`：环境安装、当前进度和续作交接记录。
- `deliverables/`：纳入仓库的 W2、W3 周文档与 PDF。
- `archive/`：历史交付版本，仅用于追溯，不作为当前执行入口。

当前 W3 操作入口为 [W3_run_and_delivery.md](operations/W3_run_and_delivery.md)，包含一键运行、核心/Notebook依赖、参数、产物位置和数据限制。算法规则与设计位于主项目 [清洗规则](../reports/w3_cleaning_rules.md)、[特征工程设计 v1](../reports/feature_engineering_design_v1.md)。

W3 周计划、完成报告和验收清单保存在 [deliverables/week3](deliverables/week3/)，W2 说明保存在 [deliverables/week2](deliverables/week2/)。代码和证据继续使用同一个仓库根目录。继续开发时阅读 [当前交接](operations/当前工作进度与续作交接.md) 顶部的最新周状态；下方早期环境记录用于追溯。
