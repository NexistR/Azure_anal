## 2. 数据定位与重要声明

### 代理数据声明

**本数据集是公开的电信行业代理/教学数据，不是 Microsoft Azure 内部真实客户数据。**

所有分析结论、字段映射和业务假设均基于此公开代理数据；结果不能直接表述为 Azure 实测事实。业务逻辑基于一般云服务/订阅模式，字段映射基于 Telco 实际可用字段。

### 行业背景

数据集模拟电信服务提供商的客户流失场景，包含订阅服务、合同类型、支付方式、月度/累计费用等字段。适用于练习流失预测、客户细分和价值分析。

## 4. 标签定义

### 流失标签：Churn

| 属性 | 值 |
|------|---|
| **字段名** | `Churn` |
| **含义** | 客户是否已流失（取消订阅/停止服务） |
| **数据类型** | 字符串（原始） |
| **原始取值** | `"Yes"` = 已流失，`"No"` = 未流失 |
| **标准转换规则** | `"Yes"` → 1，`"No"` → 0 |
| **分布** | Yes: 1,869 (26.54%)，No: 5,174 (73.46%) |
| **空值/未知值** | 0（无缺失） |
| **类别不平衡** | ⚠️ 流失类占 26.54%，需在 W5 考虑不平衡处理策略 |

**重要限制**：
- 数据集未提供流失的精确定义（如宽限期、退款窗口、服务中断定义）
- 缺少标签确认日期和观察窗口
- MVP 将 `Churn` 视为二分类目标，不区分主动/被动流失

## 5. 时间范围与观察窗口

### 时间字段可用性

| 时间概念 | 可用性 | 说明 |
|---------|--------|------|
| **快照时间/数据截止日** | ❌ 不可用 | 数据集不包含统一的观察截止日期 |
| **注册日期/首次订阅日** | ❌ 不可用 | 无法确定客户开始时间 |
| **流失日期/取消日期** | ❌ 不可用 | 只有流失状态，无事件时间 |
| **服务变更日期** | ❌ 不可用 | 无服务添加/移除的时间序列 |
| **交易日期** | ❌ 不可用 | 无购买/支付时间序列 |

**唯一时间相关字段**：`tenure`（客户年限，单位：月），表示客户已订阅的总月数。

### 观察窗口定义

**⚠️ 重要限制**：由于缺少时间字段，当前项目**无法定义严格的观察截止日和预测窗口**。

| 概念 | 当前状态 | 影响 |
|------|---------|------|
| **观察截止日** | 未定义 | 无法确保"特征只使用截止日前的信息" |
| **预测窗口** | 未定义 | 无法表述为"预测未来 X 天内流失" |
| **标签延迟** | 未定义 | 无法模拟真实部署的标签滞后 |
| **时间切分验证** | 不可行 | 无法按时间划分训练/测试集，只能随机切分 |

**MVP 降级策略**：
- W5 使用**随机分层切分**（stratified split），保持标签比例
- 模型定位为**静态客户快照分类**，而非真实的时间窗口预测
- 在报告中明确说明时间限制，不声称"严格时间验证"

**风险登记**：已将"缺少时间字段"登记为 P0 风险，影响特征工程（无趋势特征）、验证策略（无时间切分）和模型解释（无法区分因果）。

## 6. 价值字段与价值代理

### MonthlyCharges（月度费用）

| 属性 | 值 |
|------|---|
| **字段名** | `MonthlyCharges` |
| **含义** | 客户当前的月度订阅费用 |
| **数据类型** | 浮点数 |
| **单位** | 美元（推测，数据集未明确说明） |
| **范围** | 18.25 - 118.75 |
| **均值** | 64.76 |
| **中位数** | 70.35 |
| **空值** | 0 |

**业务含义**：表示客户当前的月度订阅价格，反映当前服务组合和价格层级。

### TotalCharges（累计费用）

| 属性 | 值 |
|------|---|
| **字段名** | `TotalCharges` |
| **含义** | 客户历史累计支付的总费用 |
| **原始数据类型** | ⚠️ 字符串（object），需转换为数值 |
| **目标数据类型** | 浮点数 |
| **唯一值数** | 6,531（几乎每个客户不同） |
| **空值** | 0（但有 11 个空格字符串 `" "`） |
| **质量问题** | ⚠️ 11 行为空格字符串，无法直接转换为数值 |

**业务含义**：表示客户订阅期间的累计支付金额，理论上应约等于 `tenure × MonthlyCharges`（需在 D5 质量审计中验证一致性）。

**清洗策略**（W3）：
- 空格字符串转为 `NaN`
- 检查与 `tenure` 和 `MonthlyCharges` 的关系
- 决定是删除、插补还是保留缺失

### 价值代理定义

**⚠️ 重要边界**：数据集**不包含成本、毛利或真实 CLV 数据**。

| 价值概念 | 可用性 | W8 使用策略 |
|---------|--------|------------|
| **收入** | 部分（`MonthlyCharges`、`TotalCharges`） | 作为透明的价值代理 |
| **成本** | ❌ 不可用 | 无法计算真实毛利 |
| **毛利** | ❌ 不可用 | 不能声称"毛利分析" |
| **正式 CLV** | ❌ 不可用 | 范围外，W8 不产出 BG/NBD 或 Gamma-Gamma 模型 |

**价值代理策略**：
- W8 使用 `MonthlyCharges`（当前月收入潜力）或 `TotalCharges`（历史价值）作为**透明的简化价值代理**
- 在报告中明确说明："使用月度费用作为客户价值代理，不等于真实毛利或 CLV"
- 价值代理用于风险-价值四象限分层，而非财务 ROI 计算

## 7. 特征字段可用时间与泄漏标记

每个字段在预测时的可用性：

| 字段类别 | 可用性 | 泄漏风险 | 说明 |
|---------|--------|---------|------|
| **客户 ID** | ✅ 预测时可用 | 无 | 不作为特征，仅用于索引 |
| **人口统计** | ✅ 预测时可用 | 低 | `gender`、`SeniorCitizen`、`Partner`、`Dependents` |
| **客户年限** | ✅ 预测时可用 | 低 | `tenure`（静态快照值） |
| **服务订阅** | ✅ 预测时可用 | 低 | 9 个服务字段，反映当前订阅状态 |
| **合同与支付** | ✅ 预测时可用 | 低 | `Contract`、`PaperlessBilling`、`PaymentMethod` |
| **费用字段** | ✅ 预测时可用 | 低 | `MonthlyCharges`、`TotalCharges`（当前快照值） |
| **流失标签** | ❌ **禁止作为特征** | **高** | `Churn` 是目标变量，不得进入特征 |

**泄漏检查规则**：
- `Churn` 及其任何派生字段（如 `Churn_encoded`）禁止进入特征
- 由"取消结果"派生的字段（如"取消原因"、"取消反馈"）属于标签泄漏，需排除
- 在 W4 特征工程时，逐一检查新特征的时间可用性

**重要限制**：由于缺少时间字段，**无法验证特征是否包含未来信息**。所有字段都是静态快照，无法区分"预测时已知"和"标签确认后才记录"。

## 8. 合并规则与数据集关联

### Telco 与其他数据集的合并策略

| 目标数据集 | 关联可行性 | 当前决策 | 前置条件 |

| **SaaS Churn Rate** | 不适用 | 仅参考，不合并 | 行业汇总表，非客户级 |

**合并前置条件**（如 W2+ 尝试整合工单数据）：
1. 验证工单数据的客户标识字段与 Telco `customerID` 的对应关系
2. 检查客户 ID 交集和覆盖率
3. 验证时间口径（工单时间是否与 Telco 快照一致）
4. 先聚合工单到客户级（如工单数、平均严重度），再用 `pd.merge(validate="one_to_one")` 合并
5. 禁止笛卡尔积式合并导致行数膨胀

**当前状态**：W1 只分析 Telco 主数据集，不强行合并无共同 ID/时间的数据。
